出典・利用条件

World Bank Indicators、Open-Meteo Historical Weather API / ERA5、Beck et al. Köppen-Geiger V3、Ember Yearly Electricity Data、FAO FAOSTAT、Natural Earthの公開データを加工・統合しています。統計の対象年・定義は項目ごとに異なります。欠損値は未収録であり、0を意味しません。

出典詳細とライセンス：DATA_SOURCES_AND_LICENSES.md。FAOSTATの利用条件を遵守し、FAOが本サイトを推奨・承認していると示唆しません。

学習用データは出典ごとに利用条件が異なります。公開・改変時は同梱の出典一覧を確認してください。
